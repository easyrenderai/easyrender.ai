Ilumina el producto y el fondo blanco por separado siempre que puedas. Aleja el objeto del fondo para controlar la luz que rebota y conservar el contorno. Expón primero para la pieza y ajusta después el blanco. Revisa las aristas claras y la sombra de contacto antes de exportar.

## ¿Cómo montas el fondo blanco?

Curva el papel blanco detrás del producto para que desaparezca la línea del suelo. Coloca una fuente difusa amplia a un lado y un reflector en el otro. Si la pieza es blanca, acerca una cartulina oscura fuera de cuadro para recuperar el perfil.

Deja fijos el trípode, la pieza y las luces. Cambia un ajuste cada vez y amplía el detalle más claro y la base para comprobar que siguen visibles.

## ¿Cuánto conviene retocar?

Corrige el color y el polvo antes de ajustar el blanco. Si recortas, comprueba el borde sobre gris para detectar halos. Mantén una sombra de contacto natural cuando el canal la admita.

Exporta una muestra al tamaño de la ficha y compárala con el resto del catálogo. Conserva el original para repetir encuadre y luz en próximas variantes.

## ¿Qué deberías revisar antes de publicar?

| Síntoma                   | Ajuste                                              |
| ------------------------- | --------------------------------------------------- |
| Desaparece un asa clara   | Añade una cartulina oscura y vigila las altas luces |
| El fondo sale gris        | Ilumina el fondo por separado                       |
| El producto parece flotar | Recupera el contorno o la sombra de contacto        |

## FAQ

### ¿Puedo usar una sola luz?

Sí. Prueba con una ventana o luz difusa y un reflector. Separa la pieza del fondo y corrige el fondo de forma local si hace falta. Mantén el montaje para el siguiente artículo.

### ¿Siempre tiene que ser blanco puro?

Comprueba las normas de cada canal. Para tu tienda, usa un fondo coherente y conserva el límite claro entre la pieza y el fondo. Guarda exportaciones específicas cuando cambien los requisitos.

### ¿Cómo evito un halo blanco?

Examina la máscara sobre un fondo oscuro al tamaño original. Deshaz el aclarado excesivo del borde y corrige la máscara solo en la zona afectada.
