## ¿Cómo fotografías las cuatro vistas útiles?

Para el lateral, baja la cámara hasta ver el perfil completo. Gira el zapato y conserva la altura para el talón. Coloca la suela frente a cámara para mostrar el dibujo y acércate después a la lazada o a las costuras.

## ¿Cómo mantienes consistencia entre pares?

Marca la posición y repite el recorte principal. Verifica que cordones, etiqueta y flanco pertenecen al SKU y color correctos. Si muestras el par, deja visibles las dos piezas sin esconder el rasgo que quieres enseñar.

## ¿Qué deberías revisar antes de publicar?

| Vista           | Qué enseñar                  |
| --------------- | ---------------------------- |
| Perfil exterior | Puntera, mediasuela y cuello |
| Trasera         | Forma del talón y tirador    |
| Suela           | Dibujo y borde               |
| Detalle         | Cierre, costura o textura    |

## FAQ

### ¿Muestro el par en la primera foto?

Consulta las reglas del canal y elige la vista que identifica mejor el modelo. Una foto aparte del par puede enseñar el conjunto.

### ¿Puedo reutilizar la foto de suela?

Solo si la suela es igual entre esas variantes. Coteja el color y el dibujo además de la forma.

### ¿Cómo fotografío un zapato negro?

Usa luz amplia y un reflector para sostener el detalle. Amplía las costuras y la textura antes de cambiar de modelo.
