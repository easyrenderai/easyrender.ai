Start with a sharp photo that shows the front, a side and the furniture’s feet. Review the generated angles for its distinctive parts before building the model. After export, open the actual GLB separately and check the silhouette, surfaces and details at the size buyers will see.

## Which image should you start from?

Use a three-quarter view with the furniture isolated. Leave space below the legs and avoid objects covering the outline. Lock the exposure so a light tabletop keeps detail and dark hardware stays visible. Keep real photographs of the other surfaces for review.

## How do you accept the model?

Compare the preview with the source and your reference views. Count legs, handles and openings. Open the built model, turn it around and check the joins and underside. Our public coffee-table GLB has 16,228 triangles and takes 322,876 bytes. Measure your own file against the destination’s budget.

## What should you check before publishing?

| Check      | Accept when                                        |
| ---------- | -------------------------------------------------- |
| Part count | Visible parts match the reference                  |
| Finish     | The product is still recognisable in neutral light |
| Export     | It opens in the intended viewer                    |

## FAQ

### Should I photograph the back separately?

Keep it as a reference if the rear describes something important. A generated angle is a prediction. Use physical photos for details that must be confirmed.

### What if a thin leg blends into the background?

Change the background or light to separate its edge. Leave enough camera distance to include the entire object when the legs spread out.

### Which file do I send to the shop?

Start with the format accepted by the destination. Test the transferred file itself and retain the reference photos and editable source.
