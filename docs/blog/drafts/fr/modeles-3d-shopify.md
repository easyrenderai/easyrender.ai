Ajoutez un fichier GLB ou USDZ à la galerie média d'un produit Shopify et prévisualisez-le avec le thème de votre boutique. Vérifiez-le à la fois sur un téléphone et sur un ordinateur. Gardez une photo de produit en premier élément de média afin que la liste reste fonctionnelle pendant le chargement du modèle.

![Illustration : carton ouvert, moitié en matériau, moitié en fil de fer](../covers/shopify-3d-models.webp "Illustration éditoriale réalisée dans Blender.")

## Qu'est-ce que vous devez vérifier avant l'upload ?

Choisissez un produit existant avec des photos claires. Ouvrez le modèle dans un lecteur autonome pour vérifier l'orientation, les surfaces et les textures. Enregistrez la taille du fichier et sélectionnez un miniatures qui montre ce que le modèle apporte.

Vérifiez les formats actuellement pris en charge et les limites d'upload dans le guide média de Shopify. Le thème doit supporter la média de produit 3D ou être adapté pour l'afficher. Confirmez cela sur un produit en brouillon ou sur un thème de développement avant de procéder.

## Comment trouver un lecteur manquant ?

Ouvrez le produit dans l'administration Shopify et ajoutez le fichier dans la section Média. Attendez que le traitement se termine puis enregistrez le produit. Ouvrez la prévisualisation du point de vente, sélectionnez le modèle et faites-le tourner vers l'arrière et le dessous.

Si le modèle fonctionne dans l'administration mais pas dans le point de vente, vérifiez d'abord la section média produit du thème. Testez la vue mobile et une session fraîche. Lorsque vous activez l'AR, ouvrez-la sur un appareil compatible puis retournez dans le magasin.

## Qu'est-ce que vous devez vérifier avant la publication ?

| Qu'est-ce qui se passe                                                          | Où chercher                            |
| ------------------------------------------------------------------------------- | -------------------------------------- |
| Le fichier a été rejeté                                                         | Formats et limites de fichier          |
| Prévisualisation dans l'administration fonctionne mais aucun lecteur n'apparaît | Support du média produit dans le thème |
| Le lecteur fonctionne mais l'AR ne s'ouvre pas                                  | Appareil, navigateur et fichier AR     |

## Questions fréquentes

### Tous les thèmes Shopify affichent-ils 3D ?

Shopify liste les thèmes avec support médias produits. Vérifiez la version utilisée en production et le modèle de produit où l'objet apparaît. Un thème personnalisé pourrait nécessiter des modifications.

### Quel fichier dois-je télécharger ?

Commencez par un format de modèle accepté par Shopify. Vérifiez le fichier source dans un autre lecteur, puis vérifiez les médias traités dans le point de vente. Conservez le modèle original pour des corrections ultérieures.

### Dois-je remplacer la photo d'entrée par un modèle ?

Non, remplacer la photo par un modèle n’est pas nécessaire. Ajoutez le modèle dans la section Média de l’administration Shopify. Vérifiez que le thème supporte le 3D en mode mobile ou en brouillon, car le modèle peut ne pas s’afficher en point de vente.
