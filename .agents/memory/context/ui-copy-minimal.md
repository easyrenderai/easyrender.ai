---

name: ui-copy-minimal
description: Do not add hint, helper or explanatory text to the UI; fix the behaviour or use an icon
type: feedback
---

The owner does not want hint or helper prose added to pages (for example a gesture hint on the AR
page). The app topbar is icons only, except credits and language.

**Why:** the product surface is meant to stay out of the way of the result (`DESIGN.md`); extra
prose is clutter.
**How to apply:** when a control is confusing, change the behaviour or the control. If copy is truly
needed keep it to a label, or ask once. Icon-only is preferred. New strings still go in all six
message files.
