Start with a sharp photo that shows the front, a side and the furniture’s feet. Review the generated angles for its distinctive parts before building the model. After export, open the actual GLB separately and check the silhouette, surfaces and details at the size buyers will see.

![Editorial rendering: low bench, half solid and half wireframe](/blog/illustrations/furniture-model-from-photo/hero.webp "Editorial illustration made in Blender.")

## Which image should you start from?

Use a three-quarter view with the furniture isolated. Leave space below the legs and avoid objects covering the outline.

Lock the exposure so a light tabletop keeps detail and dark hardware stays visible. Keep real photographs of the other surfaces for review.

![Source photo and 3D preview of the coffee table](/blog/figures/furniture-model-from-photo/coffee-table-photo-model.jpg "Reference photo at left and a still of the exported EasyRender model at right.")

## How do you build the model?

1. Upload a sharp photo with the whole piece visible.
2. Open the free angle preview and check the tabletop, supports and distinctive details.
3. When the preview is ready for your use case, confirm the quoted build and start it.
4. Download the resulting GLB and open it in the target viewer before adding it to the product page.

## How do you accept the model?

Compare the preview with the source and your reference views. Count legs, handles and openings.

Open the built model, turn it around and inspect the joins and underside. Measure your own file against the destination’s budget.

## What should you check before publishing?

| Check      | Accept when                                        |
| ---------- | -------------------------------------------------- |
| Part count | Visible parts match the reference                  |
| Finish     | The product is still recognisable in neutral light |
| Export     | It opens in the intended viewer                    |

## FAQ

### Should I photograph the back separately?

Keep it as a reference if the rear describes something important. A generated angle is a prediction.

Use physical photos for details that must be confirmed. A level rear view helps you verify where the legs attach, whether a seam continues, and how the back is finished.

### What if a thin leg blends into the background?

If a thin leg blends into the background, adjust the background or lighting to define its edge. Keep sufficient camera distance to capture the full object when legs spread out. Next, check that the leg’s edge is clearly visible in the photo before modeling.

### Which file do I send to the shop?

Start with the format accepted by the destination. Test the transferred file itself and retain the reference photos and editable source. For an interactive web viewer choose GLB where the platform accepts it, then check orientation, materials and which product variant received the upload.
