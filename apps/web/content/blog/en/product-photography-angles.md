Choose each product photo to answer a question. Start with a view that explains the shape, then add the angles that show how the product fits together or works. A rear view, a close-up or a shot with the product open often answers more than another nearly identical front angle.

![Editorial rendering: backpack, half solid and half wireframe](/blog/illustrations/product-photography-angles/hero.webp "Editorial illustration made in Blender.")

## Which angle should come first?

Start with three quarters for an object whose depth matters, such as a bag or a chair. Use the front when the face, shape or printed information identifies the item quickest. Check the crop at thumbnail size.

For a Merchant Center listing, use the [main image field](https://support.google.com/merchants/answer/6324350) for the primary view.

Leave enough room around the product for the site’s crop. Keep the lead angle and framing consistent across variants, and add detail images where materials or hardware actually differ.

## Which gaps should the next photos solve?

Write the questions a buyer would ask without handling the item and assign a view to each. For a bag, show the back, opening and strap attachment. For a shoe, show the sole, and for furniture add a rear or underside view if the exposed construction matters.

Place the answers in order of importance. A close-up is more useful when a wider shot tells the reader where the detail sits.

## What should you check before publishing?

| View                             | Question it answers                                                                     |
| -------------------------------- | --------------------------------------------------------------------------------------- |
| Front or three-quarter           | What is this item and what shape is it?                                                 |
| Rear, side or underside          | How is the part I cannot see constructed?                                               |
| Open or in use                   | What can I do with it?                                                                  |
| Detail                           | What does the material or mechanism look like up close?                                 |
| Beside a familiar object         | How can I picture the item in use? Check the actual measurements in the specifications. |
| Same front angle on two variants | What changes when I select a different finish?                                          |

## Select the detail that changes the decision

In the generated armchair view, the back and bent tubing are visible together. Use that as a shooting prompt. If the real chair has a fastening that the view cannot verify, take a physical photograph of the back before completing the listing.

| Product                        | Useful second angle | What it explains             |
| ------------------------------ | ------------------- | ---------------------------- |
| Chair with a contrasting frame | Rear three-quarter  | How the frame meets the back |
| Backpack with external pockets | Open top            | The pocket layout and access |
| Shoe with a patterned outsole  | Underside           | Tread layout and heel shape  |

## Check the gallery at listing size

| Check           | Action                                                                |
| --------------- | --------------------------------------------------------------------- |
| Thumbnail crop  | Keep the front, top and identifying detail inside the visible area    |
| Adjacent images | Drop a view when it repeats the previous picture's information        |
| Variants        | Repeat the same main angle and show the actual difference in a detail |

## Fix the views that leave a question open

| What you see                            | Likely cause                                        | Fix                                              |
| --------------------------------------- | --------------------------------------------------- | ------------------------------------------------ |
| The first photo shows a flat silhouette | The depth is hidden by a front view                 | Take a three-quarter frame                       |
| The package label is hard to read       | A diagonal shot foreshortens the print              | Take a straight front view                       |
| Two photos show the same features       | The viewpoint barely changed                        | Replace one with a rear or detail shot           |
| A close-up has no context               | The crop removes the connection to the whole object | Insert a wider view before the close-up          |
| A fastening disappears on mobile        | The thumbnail crops the edge                        | Leave margin and test the crop before export     |
| Two finishes are hard to tell apart     | Angle or lighting changes between variants          | Repeat the setup and show their material details |

## FAQ

### How many photos should I use?

Start with a lead view and add other angles when they answer a different question. For a chair, add the side, back or one detail according to what shoppers still need to see. Remove near duplicates and check the photo requirements for each place you list the product.

### When is a straight front view better?

Use a straight front view when the item’s face, shape, or printed details identify it most quickly. Take a front shot with clear label and consistent background for easy recognition. Check the thumbnail crop to ensure the product’s key features are visible and not cut off.

### Can a 3D model replace the back photo?

A 3D model cannot replace the back photo if it contains features the buyer needs to verify. Use both when the real photo confirms details and the model offers context. Check that the back photo shows all key features clearly and is taken under consistent lighting.
