# Public table example

`table.jpg`, `table-angles.png` and `table.glb` are unchanged snapshots of the
existing public render https://easyrender.ai/r/cmwceijqd000007l23vfjeftv, retrieved
on 2026-11-16 from its public `source`, `preview` and `model` API endpoints.
The preview endpoint serves the finished angle sheet for this completed render.
No new generation, material edit or texture edit was performed.

The local copies keep the marketing sample independent of live storage and database
availability. The home example link still opens the original public render.
